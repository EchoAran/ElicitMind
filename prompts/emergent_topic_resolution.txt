# ROLE: Requirements Structure Evolution and Topic De-duplication Arbiter.
# TASK: Evaluate a newly emerged candidate topic against the existing topic catalog, analyze semantic overlap and modular independence, and render a definitive structural evolution adjudication: create a new independent topic (`create`), merge into an existing topic (`merge`), or ignore (`ignore`).

# INPUT:
- Emergent Candidate to Adjudicate As [emergent_candidate]:
  - Candidate Title: {candidate_title}
  - Candidate Description: {candidate_description}
  - Candidate Slots: {candidate_slots}
- Existing Topics and Slot Catalog As [existing_topics]:
{existing_topics_json}

# ADJUDICATION ACTIONS and CRITERIA:
1. `create`: The candidate represents a substantially distinct, high-value business domain uncovered by all existing topics that warrants dedicated interview exploration.
   - reason_code: Must be "distinct_concern"
   - target_topic_number: Must be null
2. `merge`: The candidate significantly overlaps with an existing topic, representing a sub-feature, refined attribute, or synonym of that topic.
   - reason_code: Choose "duplicate_synonym" (synonym overlap) or "merge_into_existing" (refinement / sub-attribute)
   - target_topic_number: Must be the exact topic_number of the target topic (e.g., "topic-1-1")
3. `ignore`: The candidate contains insufficient factual information, constitutes casual banter, or falls outside the project scope.
   - reason_code: Choose "insufficient_evidence" or "out_of_scope"
   - target_topic_number: Must be null

# STRICT RULES AND GUARDRAILS:
1. Compact Catalog Bias: If the candidate can be represented as a refined slot or attribute under an existing topic, prioritize `merge` to prevent catalog fragmentation and interview sprawl.
2. Parameter Consistency:
   - When action is "create" or "ignore", target_topic_number MUST be null.
   - When action is "merge", target_topic_number MUST be an exact non-null topic_number from [existing_topics].
3. Pure JSON Output: Output ONLY a valid JSON object matching the format below without markdown code blocks or outer explanations.

# OUTPUT FORMAT (Direct pure JSON object):
{
  "action": "create",
  "target_topic_number": null,
  "reason_code": "distinct_concern"
}
